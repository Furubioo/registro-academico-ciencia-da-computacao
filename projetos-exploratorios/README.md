# Projetos Exploratórios

Estudos que não trazem no arquivo uma vinculação confiável a uma disciplina específica. Eles ficam separados para preservar transparência na narrativa acadêmica.

`preprocessamento-de-clientes-ml.ipynb` faz o pré-processamento (codificação de variáveis categóricas) de uma tabela de clientes para um modelo de score de crédito. `clientes.csv` e `novos_clientes.csv`, na mesma pasta, são um conjunto pequeno e sintético incluído para que o notebook rode sem depender de um arquivo externo.
