# Programação Orientada a Objetos em Java

Projetos do terceiro período sobre classes, encapsulamento, herança, polimorfismo, interfaces e exceções. Cada subdiretório é um exercício ou pequeno sistema independente.

## Executar

```bash
cd FormaGeometrica
javac *.java
java Main
```

Use JDK 17 ou superior. Alguns exercícios são bibliotecas de classes sem um programa demonstrador; todos os diretórios foram mantidos para preservar a evolução da modelagem orientada a objetos.
