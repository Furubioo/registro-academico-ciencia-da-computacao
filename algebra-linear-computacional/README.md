# Álgebra Linear Computacional

Notebooks sobre operações matriciais, sistemas lineares, Cifra de Hill e transformações geométricas 2D e 3D. Eles conectam álgebra linear a criptografia, visualização e modelagem populacional.

## Executar

```bash
python -m pip install jupyter numpy sympy matplotlib
jupyter notebook
```

Cada notebook traz seu contexto e suas bibliotecas nas primeiras células.
