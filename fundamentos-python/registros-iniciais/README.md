# Registros iniciais de aula

Estes arquivos guardam tentativas iniciais de Flávio feitas durante as aulas. Alguns reúnem vários enunciados em comentários, por isso ficam separados dos exercícios independentes em `../exercicios/`.

Eles são mantidos como registro de evolução; para executar exemplos completos e individualizados, use a coleção principal.

`colecao-de-exercicios-com-for-2.py`, `colecao-de-exercicios-com-funcoes-1.py` e `colecao-de-exercicios-com-funcoes-e-recursao.py` vieram de sessões de estudo com Maria Clara, que fizeram as mesmas aulas juntos.
