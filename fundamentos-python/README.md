# Fundamentos da Programação em Python

Coleção do primeiro período dedicada a lógica, leitura de dados, condicionais, laços, strings, funções e recursão. Os **61 exercícios independentes** ficam em `exercicios/`, com nomes que descrevem a tarefa resolvida.

| Pasta | Exercícios | Conceitos |
| --- | ---: | --- |
| `condicionais` | 8 | regras de negócio, comparações e classificações |
| `lacos-e-numeros` | 33 | `for`, `range`, contagens, médias e propriedades numéricas |
| `validacoes-e-while` | 8 | repetição condicional, senhas e validação de entrada |
| `strings` | 6 | caracteres, palavras e filtros de texto |
| `funcoes-e-recursao` | 6 | decomposição, fatorial e somatórios |

A pasta `registros-iniciais/` preserva oito arquivos de aula (de Flávio e de sessões de estudo com Maria Clara) que agrupavam várias tentativas no mesmo arquivo. Eles foram renomeados para deixar seu papel claro; os exercícios organizados ficam em `exercicios/`.

## Executar

```bash
python3 exercicios/lacos-e-numeros/numero-perfeito.py
```

Use Python 3. Cada programa é independente e lê os dados pelo terminal.
