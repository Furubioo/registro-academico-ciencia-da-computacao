# Cálculo Computacional

Notebooks de limites, derivadas, integrais, comprimento de curvas, volumes e integrais duplas. O uso de Python serve para explorar e verificar visualmente conceitos de cálculo aplicados à computação.

## Executar

```bash
python -m pip install jupyter numpy sympy matplotlib scipy
jupyter notebook
```

Abra um notebook por vez. Os arquivos com `flavio-daniel` na origem representam atividades colaborativas identificadas no próprio material. `prova-pratica-derivadas-em-dupla.ipynb` preserva os autores informados no arquivo original.
