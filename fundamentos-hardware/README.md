# Fundamentos de Hardware

## Jogo de Memória para Raspberry Pi

Projeto da disciplina de Fundamentos de Hardware que usa botões e LEDs conectados a GPIO. O programa gera uma sequência de cores e verifica a resposta do jogador.

## Requisitos

```bash
python -m pip install RPi.GPIO
python jogo-memoria-rpi.py
```

Execute apenas em Raspberry Pi com os pinos descritos no código devidamente conectados. O programa controla hardware físico.
